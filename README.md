# Cristo Republic Coffee

Website for Cristo Republic Coffee: Home, Shop, Our Coffee, About Us, Blog, product pages and the Coffee Club.

**Live site:** https://fredyyanes-hash.github.io/cristo-republic-coffee/

Plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser to run it locally.

- `styles.css` is the original stylesheet; `fixes.css` loads after it with the redesign.
- `cart.js` holds the product catalog, the cart (saved in the browser) and the Shop filters.
- Photos and the Our Coffee video are compressed copies of the originals so the site loads quickly.
- Every photo the site uses lives in `images/`; nothing is linked from other websites.
